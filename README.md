## 🚀 Проекты

### 🏆 Проекты в Профкоме студентов физфака МГУ

Активно участвую в разработке IT-решений для студентов физического факультета МГУ в рамках приложения [Твой ФФ!](https://github.com/profcomff).

Полная документация по проектам доступна по адресу: [docs.profcomff.com](https://docs.profcomff.com/index.html)

#### Основные проекты:

### [API «Рейтинг преподавателей»](https://github.com/profcomff/rating-api)
Система оценки и комментирования преподавателей с функциями фильтрации и администрирования.
- `Python` `FastAPI` `SQLAlchemy` `PostgreSQL` `Vue.js`

### [API «Аутентификация и авторизация»](https://github.com/profcomff/auth-api)
Сервис авторизации с поддержкой OAuth2 и различных провайдеров (Yandex/VK/Telegram).
- `Python` `FastAPI` `OAuth2` `PostgreSQL`

### [Фронтенд приложения «Твой ФФ»](https://github.com/profcomff/webapp-ui)
Веб-приложение для студентов физического факультета с расписанием занятий, 
информацией о преподавателях, возможностью печати документов и другими полезными сервисами.
- `Vue.js` `TypeScript` `REST API`
